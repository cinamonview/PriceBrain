# 1. 프로젝트 개요

## 1.1 프로젝트 정의

PriceBrain은 다양한 판매처에서 수집한 상품 가격 데이터를 통합하고,
시간에 따른 가격 변동을 분석하여 사용자에게 단순한 최저가뿐만 아니라
합리적인 구매 시점을 제안하는 AI 기반 스마트 쇼핑 어시스턴트이다.

PriceBrain은 다음 질문에 답하는 것을 목표로 한다.

> "이 상품은 어디에서 가장 저렴한가?"

그리고 더 나아가,

> "현재 가격은 평소보다 저렴한가?"

> "지금 구매하는 것이 좋은가?"

> "조금 더 기다리는 것이 합리적인가?"

에 대한 데이터 기반 판단을 제공한다.


# 2. 프로젝트 목표

## 2.1 핵심 목표

PriceBrain의 핵심 목표는 단순한 가격비교가 아니다.

현재 가격과 과거 가격 데이터를 분석하여
사용자가 합리적인 구매 결정을 내릴 수 있도록 돕는 것이다.

이를 위해 다음 기능을 단계적으로 구현한다.

1. 상품 검색
2. 판매처별 가격 비교
3. 가격 이력 저장
4. 가격 변동 분석
5. 데이터 시각화
6. 구매 적정성 분석
7. AI 기반 가격 분석
8. AI 기반 구매 타이밍 추천


## 2.2 핵심 가치

PriceBrain은 다음 네 가지 가치를 중심으로 개발한다.

- 가격 비교
- 데이터 분석
- 데이터 시각화
- AI 기반 구매 의사결정 지원


# 3. 차별화 전략

기존 가격비교 서비스가 주로 현재 가격 비교에 집중한다면,
PriceBrain은 시간에 따른 가격 변화를 분석하는 것을 핵심 차별화 요소로 한다.

예를 들어 단순히:

> 최저가: 1,029,000원

을 보여주는 것에서 끝나지 않는다.

다음과 같은 정보를 함께 제공한다.

> 현재 가격은 최근 30일 평균보다 5.3% 낮습니다.

> 최근 7일간 가격은 하락 추세입니다.

> 현재 가격은 최근 30일 최저가와 30,000원 차이입니다.

이를 통해 사용자가 가격을 "보는 것"에서
가격을 "이해하는 것"으로 발전시키는 것을 목표로 한다.

# 5. GPU 카테고리를 선택한 이유

GPU는 PriceBrain의 핵심 기능을 검증하기에 적합한 카테고리로 판단한다.

주요 이유:

- 비교적 명확한 모델 체계
- 다양한 제조사 제품 존재
- 다양한 판매처 존재
- 제품별 가격 차이 존재
- 가격 변동성이 존재
- 동일 GPU 모델을 여러 제조사가 제작
- 스펙 데이터가 비교적 구조화되어 있음
- 가격과 성능을 함께 분석할 수 있음

또한 GPU는 다음과 같은 단계적 분석이 가능하다.

> GPU 모델 비교

→ 실제 제품 비교

→ 판매처별 가격 비교

→ 가격 이력 분석

→ 가격 대비 성능 분석

→ 구매 타이밍 분석

# 7. 핵심 사용자 시나리오

## 7.1 상품 검색

사용자가 검색창에 상품명을 입력한다.

예:

> RTX 5070 Ti

시스템은 관련 상품과 GPU 모델을 검색하여 결과를 제공한다.


## 7.2 판매처 가격 비교

사용자가 특정 제품을 선택하면
판매처별 가격을 비교한다.

예:

| 판매처 | 상품 가격 | 배송비 | 실구매 예상가격 |
|---|---:|---:|---:|
| 판매처 A | 1,049,000 | 무료 | 1,049,000 |
| 판매처 B | 1,029,000 | 5,000 | 1,034,000 |
| 판매처 C | 1,079,000 | 무료 | 1,079,000 |


## 7.3 가격 변동 확인

상품 상세 페이지에서 가격 변동 그래프를 제공한다.

기본 기간:

- 7일
- 30일
- 90일

향후:

- 180일
- 365일


## 7.4 구매 적정성 확인

현재 가격과 과거 가격 데이터를 비교하여
현재 구매 상황을 분석한다.

예:

> 🟢 구매 고려

> 현재 가격은 최근 30일 평균보다 낮으며,
> 최근 최저가와도 가까운 수준입니다.

# 9. AI 기능

AI는 핵심 데이터를 확보하고 분석 기반이 안정화된 이후 단계적으로 도입한다.


## 9.1 AI 상품 매칭

판매처마다 다른 상품명을 분석하여
동일 상품 여부를 판단한다.

활용 데이터:

- 브랜드
- 모델명
- 모델번호
- SKU
- 주요 스펙
- 상품명


## 9.2 AI 가격 분석

현재 가격과 과거 가격 데이터를 기반으로
가격 상태를 자연어로 설명한다.

예:

> 현재 가격은 최근 30일 평균보다 약 6% 낮은 수준입니다.


## 9.3 AI 구매 타이밍 분석

가격 이력과 통계 정보를 기반으로
현재 구매 상황을 분석한다.

결과:

- 🟢 구매 고려
- 🟡 관망
- 🔴 구매 비추천

단, AI가 미래 가격을 확정적으로 예측한다고 표현하지 않는다.


## 9.4 향후 AI 기능

- 가격 하락 가능성 분석
- 상품 간 가성비 비교
- 자연어 상품 검색
- 리뷰 분석
- 가격 알림
- 사용자별 추천

## 24. 제품 방향

PriceBrain은 단순한 가격비교 사이트가 아니다.

PriceBrain이 제공해야 하는 것은

가격 정보

가 아니라

구매 의사결정에 도움이 되는 가격 인사이트

이다.

따라서 모든 기능 개발은 다음 질문을 기준으로 판단한다.

이 기능이 사용자가 더 합리적인 구매 결정을 내리는 데 도움이 되는가?

PriceBrain의 궁극적인 목표는

가격을 읽고,
가격을 이해하고,
더 나은 구매 결정을 할 수 있도록 돕는 것

이다.
